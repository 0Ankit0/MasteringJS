Creating a Virtual DOM from Real DOM

Goal: convert live DOM nodes into plain JavaScript objects so we can compare old UI vs new UI efficiently.

1) Function signature
function createVirtualDOM(node) {

The function receives one real DOM node and returns a virtual representation of that node.

2) Handle text nodes early
if (node.nodeType === Node.TEXT_NODE) {
  return node.textContent;
}

Text nodes do not have attributes or children arrays like elements, so returning the text keeps the structure simple.

3) Create the base virtual node object
const vNode = {
  tag: node.tagName,
  props: {},
  children: []
};

tag is the element type, props stores attributes, and children stores nested nodes.

4) Copy attributes
for (const attr of node.attributes || []) {
  vNode.props[attr.name] = attr.value;
}

This preserves state like id, class, data-*, and accessibility attributes.

5) Recurse through children
for (const child of node.childNodes) {
  vNode.children.push(createVirtualDOM(child));
}

Recursion means the same function handles nested structures of any depth.

6) Return finished virtual node
return vNode;
}

The result is a full object tree that mirrors the original DOM subtree.

Example
// Real DOM
<div id="app">
  <h1>Hello</h1>
  <p>World</p>
</div>

// Virtual DOM
{
  tag: "DIV",
  props: { id: "app" },
  children: [
    { tag: "H1", props: {}, children: ["Hello"] },
    { tag: "P", props: {}, children: ["World"] }
  ]
}

This data-first structure is easier to compare than walking the real DOM directly on every update.
