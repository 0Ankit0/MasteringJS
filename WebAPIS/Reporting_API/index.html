Reporting API

Collect browser-generated reports (like deprecations or policy violations) for monitoring.

What it helps with

  • Detect deprecated feature usage.
  • Track CSP and network policy issues.
  • Improve production observability.
if ("ReportingObserver" in window) {
  const observer = new ReportingObserver((reports) => {
    reports.forEach((report) => console.log(report.type, report.body));
  }, { buffered: true });
  observer.observe();
}
Useful in production diagnostics, but support and report types vary by browser.
