EyeDropper API

The EyeDropper API opens a native color picker so users can sample any visible screen color.

How the flow works

  1. Check browser support for EyeDropper.
  2. Create an instance with new EyeDropper().
  3. Call open() from a user gesture (like a click).
  4. Read the picked color from result.sRGBHex.
Security model: Browsers require a user interaction before opening the eyedropper.

Code example

document.getElementById("pick-color-btn").addEventListener("click", async () => {
  if (!("EyeDropper" in window)) {
    alert("EyeDropper API is not supported in this browser.");
    return;
  }

  const eyeDropper = new EyeDropper();

  try {
    const result = await eyeDropper.open();
    document.getElementById("color-value").textContent = result.sRGBHex;
    document.getElementById("color-box").style.backgroundColor = result.sRGBHex;
  } catch {
    document.getElementById("color-value").textContent = "None (Cancelled)";
  }
});
