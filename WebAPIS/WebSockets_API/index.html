WebSockets API

Open a persistent, bidirectional connection between browser and server.

Use cases

  • Chat applications
  • Realtime dashboards/games
  • Collaborative editing
const socket = new WebSocket("wss://example.com/ws");

socket.addEventListener("open", () => socket.send("Hello"));
socket.addEventListener("message", (e) => console.log("Message:", e.data));
socket.addEventListener("close", () => console.log("Closed"));
For production, add reconnect logic and heartbeat/ping handling.
