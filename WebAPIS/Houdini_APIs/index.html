CSS Houdini APIs

Houdini exposes lower-level CSS capabilities so developers can extend rendering behavior.

Main pieces

  • Paint API: custom painted backgrounds/borders.
  • Properties & Values API: register typed custom properties.
  • Layout API: custom layout algorithms (experimental).

Beginner-safe start

Start with Paint API + feature detection; use graceful fallback styles for unsupported browsers.

if ("paintWorklet" in CSS) {
  CSS.paintWorklet.addModule("paint.js");
} else {
  // fallback styles
}
Houdini support is partial across browsers. Always provide fallback CSS.
