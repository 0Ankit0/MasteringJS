CSS Typed Object Model (Typed OM)

CSS Typed OM lets JavaScript read and write CSS values as typed objects instead of raw strings.

Why this matters

  • Fewer string parsing bugs ("12px" vs 12 confusion).
  • Clearer math with CSS units.
  • Better code readability for dynamic styling and animation.

Core concepts

  • element.computedStyleMap() reads computed style values.
  • element.attributeStyleMap.set() writes typed style values.
  • CSS.px(24), CSS.percent(50), CSS.deg(45) create typed units.

Beginner example

const box = document.querySelector(".box");

// set width with a typed value
box.attributeStyleMap.set("width", CSS.px(240));

// read computed width
const widthValue = box.computedStyleMap().get("width");
console.log(widthValue.value, widthValue.unit); // e.g. 240 "px"
Use feature detection because support is still evolving: if ("attributeStyleMap" in Element.prototype)
