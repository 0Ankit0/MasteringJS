Picture-in-Picture API

Keep a video floating while users continue browsing the page.

How it works

  1. User clicks a button (required user gesture).
  2. Call video.requestPictureInPicture().
  3. Use document.exitPictureInPicture() to leave PiP mode.

Common use cases

  • Video tutorials while reading docs.
  • Live streams while multitasking.
  • Long-form content where users switch tabs/windows.

Live example

Always check support: "pictureInPictureEnabled" in document and "requestPictureInPicture" in HTMLVideoElement.prototype.
