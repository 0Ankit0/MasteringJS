CSS Font Loading API

Load fonts on demand and apply them only when they are ready.

Why use it

  • Control exactly when custom fonts are downloaded.
  • Avoid layout flashes from slow-loading fonts.
  • Track font load success/failure in JavaScript.

Core objects

  • FontFace: represents one font face.
  • document.fonts: collection of loaded/loading fonts.
  • font.load(): returns a promise when font is loaded.

const font = new FontFace("DynamicFont", "url(https://.../roboto.ttf)");
await font.load();
document.fonts.add(font);
document.body.style.fontFamily = "DynamicFont, sans-serif";
