IndexedDB API

Store structured data in-browser for offline-ready web applications.

Core concepts

  • Database: top-level container.
  • Object Store: like a table.
  • Transaction: required for read/write operations.
  • Index: query by non-primary-key fields.

Open and initialize

const request = indexedDB.open("DemoDB", 1);

request.onupgradeneeded = (event) => {
  const db = event.target.result;
  db.createObjectStore("users", { keyPath: "id", autoIncrement: true });
};

request.onsuccess = (event) => {
  const db = event.target.result;
  // use db
};

Add and read data

const tx = db.transaction("users", "readwrite");
const store = tx.objectStore("users");
store.add({ name: "Alice", age: 28 });

store.getAll().onsuccess = (e) => {
  console.log(e.target.result);
};
IndexedDB is async and event-driven. Wrap operations in helper functions for cleaner app code.
