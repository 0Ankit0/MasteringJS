Broadcast Channel API

Broadcast Channel provides same-origin communication between tabs, windows, iframes, and workers without a server roundtrip.

Why beginners should care

  • Sync login/logout state across tabs.
  • Instantly refresh data in every open tab after one tab updates it.
  • Share simple notifications in multi-tab applications.

Core API

  • new BroadcastChannel(name): opens a channel.
  • channel.postMessage(data): sends data to listeners.
  • channel.onmessage = handler: receives data.
  • channel.close(): releases resources.

Minimal example

const channel = new BroadcastChannel("app-sync");

channel.onmessage = (event) => {
  console.log("Received from another tab:", event.data);
};

function publishUpdate() {
  channel.postMessage({ type: "PROFILE_UPDATED", at: Date.now() });
}

window.addEventListener("beforeunload", () => channel.close());
