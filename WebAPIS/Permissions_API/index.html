Permissions API

Check permission status before trying feature APIs like geolocation.

Core idea

Permissions API does not directly grant permissions. It helps you inspect current status (granted, denied, prompt) so your app can react gracefully.

Beginner flow

  1. Query permission state.
  2. If granted, run feature immediately.
  3. If prompt, explain why you need access before requesting.
  4. If denied, show fallback + settings guidance.

Example: query geolocation permission

const status = await navigator.permissions.query({ name: "geolocation" });
console.log(status.state); // "granted" | "denied" | "prompt"

Example: request notifications permission

const permission = await Notification.requestPermission();
console.log(permission); // "granted" | "denied" | "default"
Support varies by permission type and browser. Always use feature detection.
