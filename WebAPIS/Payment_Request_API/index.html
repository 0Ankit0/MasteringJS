Payment Request API

Payment Request API provides a browser-native payment sheet to reduce checkout friction.

What it gives you

  • Standard UI for payment details collection.
  • Cleaner checkout code than building everything manually.
  • Potentially faster user completion on supported devices.

Core pieces

  • methodData: payment method identifiers.
  • details: totals and line items.
  • options: request payer name/email/phone/shipping.

Minimal flow

  1. Create new PaymentRequest(methodData, details, options).
  2. Call request.show() in a user gesture.
  3. Send response details to server for real payment processing.
  4. Call response.complete("success") or response.complete("fail").
const methodData = [{ supportedMethods: "basic-card" }];

const details = {
  total: {
    label: "Total",
    amount: { currency: "USD", value: "19.99" }
  }
};

const options = { requestPayerEmail: true };

const request = new PaymentRequest(methodData, details, options);
const response = await request.show();
// send response.details / response.payerEmail to your server
await response.complete("success");
Browser and payment-method support differs widely. Always provide a non-PaymentRequest checkout fallback.
