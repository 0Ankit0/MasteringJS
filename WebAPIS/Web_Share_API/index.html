Web Share API

Share text, links, and files with the device’s native share sheet.

Basics

  • Works only in secure contexts (https).
  • Usually requires a user gesture (button click).
  • Use navigator.canShare() for file checks.

Share text + URL

await navigator.share({
  title: "Web Share API",
  text: "Check this out",
  url: "https://developer.mozilla.org/"
});

Share a file

const file = new File(["Hello"], "hello.txt", { type: "text/plain" });
if (navigator.canShare?.({ files: [file] })) {
  await navigator.share({ files: [file], title: "Shared File" });
}
