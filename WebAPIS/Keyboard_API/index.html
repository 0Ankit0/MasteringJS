Keyboard Events API

Detect key presses and shortcuts like Ctrl+S for app-style interactions.

Important properties

  • event.key: actual key value (e.g., "a", "Enter").
  • event.ctrlKey, event.shiftKey, event.altKey, event.metaKey.
  • event.code: physical key location (layout-independent).

Live shortcut demo

Press Ctrl+S or Ctrl+A.

Detected: None
document.addEventListener("keydown", (event) => {
  if (event.ctrlKey && event.key.toLowerCase() === "s") {
    event.preventDefault();
    // save
  }
});
Use keyboard shortcuts carefully so you do not break expected browser/system behavior.
