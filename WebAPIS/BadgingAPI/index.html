Badging API

The Badging API lets installed web apps (PWAs) show a small badge on their app icon to indicate pending work, like unread messages or unfinished tasks.

When to use it

  • Unread chat or email count.
  • Pending approvals in a workflow tool.
  • Background sync completed or failed state indicators.

Core methods

  • navigator.setAppBadge(number?) sets a dot or numeric badge.
  • navigator.clearAppBadge() removes the badge.

Beginner flow

  1. Feature-detect support.
  2. Set badge when important state changes.
  3. Clear badge after user reads/handles the item.

Code example

async function updateBadge(unreadCount) {
  if (!("setAppBadge" in navigator) || !("clearAppBadge" in navigator)) {
    console.log("Badging API is not supported in this browser.");
    return;
  }

  try {
    if (unreadCount > 0) {
      await navigator.setAppBadge(unreadCount);
    } else {
      await navigator.clearAppBadge();
    }
  } catch (error) {
    console.error("Failed to update app badge:", error);
  }
}
Note: Badge visibility behavior depends on platform and whether the app is installed.
