Credential Management API

This API helps websites request, store, and manage sign-in credentials with browser assistance.

What problem it solves

Instead of manually handling every sign-in flow, websites can coordinate with the browser's credential store for smoother sign-in UX.

Main methods

  • navigator.credentials.get(options): ask browser for a credential.
  • navigator.credentials.store(credential): store after successful sign-in.
  • navigator.credentials.preventSilentAccess(): require explicit user mediation.

Beginner flow

  1. User signs in with form credentials.
  2. App verifies credentials on server.
  3. On success, app stores credentials for easier future sign-ins.
async function tryCredentialLogin() {
  if (!("credentials" in navigator)) return null;

  const credential = await navigator.credentials.get({ password: true });
  if (!credential) return null;

  return fetch("/login", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ id: credential.id, password: credential.password })
  });
}
Modern auth increasingly uses WebAuthn/Passkeys. Credential Management concepts still help understand browser-assisted authentication flows.
