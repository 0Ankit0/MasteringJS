Web APIs Learning Map

Beginner-first roadmap for this repository’s Web API tutorials. Start with fundamentals, then move to real-time, storage, and advanced browser APIs.

Recommended sequence: Network + URL → Storage + Permissions → UI & interaction → Background & advanced platform APIs.

1) Fundamentals (Beginner)

  • Fetch API (HTTP requests)
  • URL API (safe parsing and query params)
  • Clipboard API (copy/paste flows)
  • History API (SPA navigation basics)

2) Storage + Identity (Beginner → Intermediate)

  • Cookie Store API
  • IndexedDB API
  • Credential Management API
  • Permissions API

3) Interaction + UI (Beginner → Intermediate)

  • Drag and Drop API
  • Popover API
  • Picture-in-Picture API
  • EyeDropper API
  • Keyboard API

4) Realtime + Messaging (Intermediate)

  • Server-Sent Events
  • Broadcast Channel API
  • WebSockets API
  • Web Share API

5) Rendering + Performance + Advanced (Intermediate → Advanced)

  • CSS Font Loading API
  • CSS Typed OM API
  • CSS Custom Highlight API
  • Compression Streams API
  • Navigation API
