CSS Custom Highlight API

This API lets you highlight specific text ranges without changing HTML markup. It is ideal for search results, annotations, and review tools.

How it works (simple mental model)

  1. Create one or more Range objects that point to text positions.
  2. Wrap ranges in a Highlight object.
  3. Register highlight using CSS.highlights.set(name, highlight).
  4. Style it with ::highlight(name) in CSS.

Code example

const range = new Range();
range.setStart(textNode, 5);
range.setEnd(textNode, 15);

const highlight = new Highlight(range);
CSS.highlights.set("search-hit", highlight);
::highlight(search-hit) {
  background: #ffeb3b;
  color: #222;
}

Why it is better than wrapping with <mark> in some cases

  • No DOM mutation needed for every highlight.
  • Easy to add/remove dynamic highlights.
  • Keeps original text structure intact.
Always use feature detection: if ("highlights" in CSS).
