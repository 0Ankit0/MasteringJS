Battery Status API

The Battery Status API exposes charging and battery level information, which can help apps adjust behavior for power efficiency.

Important: This API has limited browser support and privacy concerns. Always provide fallback behavior for unsupported browsers.

What you can read

  • battery.charging: whether device is charging.
  • battery.level: charge level between 0 and 1.
  • battery.chargingTime: seconds until fully charged.
  • battery.dischargingTime: seconds until empty.

Beginner-friendly use case

If battery is low and not charging, reduce expensive updates (polling, heavy animations, high-frequency sync).

Code example

async function monitorBattery() {
  if (!("getBattery" in navigator)) {
    console.log("Battery Status API is not supported.");
    return;
  }

  try {
    const battery = await navigator.getBattery();

    const logBattery = () => {
      console.log("Charging:", battery.charging);
      console.log("Level:", Math.round(battery.level * 100) + "%");
      console.log("Charging time:", battery.chargingTime);
      console.log("Discharging time:", battery.dischargingTime);
    };

    logBattery();
    battery.addEventListener("chargingchange", logBattery);
    battery.addEventListener("levelchange", logBattery);
  } catch (error) {
    console.error("Failed to read battery status:", error);
  }
}
