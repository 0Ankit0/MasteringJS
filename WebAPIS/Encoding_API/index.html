Encoding API

The Encoding API converts text to bytes and bytes back to text. This is essential for files, network requests, streams, and binary-safe processing.

Core tools

  • TextEncoder: string → UTF-8 bytes (Uint8Array).
  • TextDecoder: bytes → string (UTF-8 by default).
  • btoa/atob: Base64 for Latin-1 compatible data (with caveats).

Beginner example: text to bytes and back

const encoder = new TextEncoder();
const decoder = new TextDecoder();

const bytes = encoder.encode("Hello, world 👋");
console.log(bytes);

const text = decoder.decode(bytes);
console.log(text); // "Hello, world 👋"

When Base64 is useful

  • Embedding small binary assets in text formats.
  • Transporting binary-like data through text-only channels.

Best practices

  • Use TextEncoder/TextDecoder for Unicode-safe workflows.
  • Use streams for large data to avoid memory spikes.
  • Validate external data before decoding.
