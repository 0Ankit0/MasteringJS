Cookie Store API

Asynchronous cookie access as a cleaner alternative to parsing document.cookie strings.

Support is still limited in some browsers. Keep a fallback for unsupported environments.

Key methods

  • cookieStore.get(name)
  • cookieStore.set({...})
  • cookieStore.delete(name)
await cookieStore.set({ name: "example_cookie", value: "Hello", expires: Date.now() + 3600_000 });
const cookie = await cookieStore.get("example_cookie");
await cookieStore.delete("example_cookie");
