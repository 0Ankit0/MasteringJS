Canvas API

Draw 2D graphics directly in the browser using JavaScript.

Beginner flow

  1. Get canvas element.
  2. Get 2D context with getContext("2d").
  3. Call drawing methods (fillRect, beginPath, arc, etc.).
const canvas = document.getElementById("demoCanvas");
const ctx = canvas.getContext("2d");
ctx.fillStyle = "#0d6efd";
ctx.fillRect(20, 20, 120, 80);
