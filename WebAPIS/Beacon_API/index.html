Beacon API

Send lightweight analytics/events to the server without blocking page unload.

When to use

  • Track “page closed” or “session ended” events.
  • Send non-critical telemetry with minimal impact.

Core method

navigator.sendBeacon(url, data) returns true/false if queued.

const payload = JSON.stringify({ event: "page_exit", at: Date.now() });
const ok = navigator.sendBeacon("/analytics", payload);
console.log("Queued:", ok);

Use Beacon for small fire-and-forget payloads, not large uploads.
