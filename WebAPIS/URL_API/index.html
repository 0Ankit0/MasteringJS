URL API

URL API gives reliable parsing and modification of URLs without fragile string splitting.

Beginner essentials

  • new URL(input): parse a URL.
  • url.searchParams: read/write query params safely.
  • URL.canParse(value): validate parseability (where supported).

Example

const url = new URL("https://example.com/products?category=books&page=2");

console.log(url.hostname); // example.com
console.log(url.pathname); // /products

url.searchParams.set("page", "3");
url.searchParams.append("sort", "price");

console.log(url.toString());
// https://example.com/products?category=books&page=3&sort=price
