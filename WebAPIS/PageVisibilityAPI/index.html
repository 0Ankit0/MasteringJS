Page Visibility API

Detect when a tab becomes hidden or visible to optimize work and UX.

Common use cases

  • Pause animations/videos in hidden tabs.
  • Throttle polling and expensive computations.
  • Log active vs idle session behavior.
document.addEventListener("visibilitychange", () => {
  if (document.hidden) {
    console.log("Tab hidden");
  } else {
    console.log("Tab visible");
  }
});
