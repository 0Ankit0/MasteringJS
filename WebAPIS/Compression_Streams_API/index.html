Compression Streams API

This API lets you compress or decompress data using web streams directly in the browser.

Where it helps

  • Large text payload processing in browser tools.
  • Client-side archive workflows.
  • Streaming transformations without loading everything into memory first.

Main classes

  • new CompressionStream("gzip" | "deflate")
  • new DecompressionStream("gzip" | "deflate")

Beginner example: compress text

async function compressText(input) {
  const encoder = new TextEncoder();
  const bytes = encoder.encode(input);

  const compressedStream = new Blob([bytes])
    .stream()
    .pipeThrough(new CompressionStream("gzip"));

  const compressedBuffer = await new Response(compressedStream).arrayBuffer();
  return new Uint8Array(compressedBuffer);
}

Good practice

Always detect support and provide a fallback path for unsupported browsers.
