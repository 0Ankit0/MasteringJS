Navigation API

The Navigation API gives modern control over same-document navigations in single-page style apps.

Why it exists

Traditional routing often mixes history.pushState and many custom events. Navigation API provides a cleaner model for intercepting and handling navigations.

Important concepts

  • navigation.navigate(url): trigger navigation.
  • navigation.addEventListener("navigate", ...): intercept and customize behavior.
  • event.intercept(): async handling for client-side route transitions.
if ("navigation" in window) {
  navigation.addEventListener("navigate", (event) => {
    if (new URL(event.destination.url).origin === location.origin) {
      event.intercept({
        async handler() {
          // fetch/render route content here
        }
      });
    }
  });
}
This API is still emerging. Keep a fallback router strategy for unsupported browsers.
