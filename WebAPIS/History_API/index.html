History API

Update URLs and navigation state in single-page apps without full page reloads.

Main methods

  • history.pushState(state, "", url): add a new history entry.
  • history.replaceState(state, "", url): replace current entry.
  • window.onpopstate: handle back/forward navigation.

Example

history.pushState({ page: "products" }, "", "/products");

window.addEventListener("popstate", (event) => {
  console.log("Restored state:", event.state);
});

Live demo

History API changes the URL/path in-browser but does not fetch page content automatically.
