Prioritized Task Scheduling API

Schedule work with priority hints so critical tasks run before background tasks.

Why it matters

Large apps can keep UI responsive by prioritizing user-visible work over non-urgent computations.

if ("scheduler" in window && "postTask" in scheduler) {
  scheduler.postTask(() => {
    console.log("User-blocking task");
  }, { priority: "user-blocking" });
}

Priority levels

  • user-blocking
  • user-visible
  • background
This API is still emerging. Use feature detection and fallback scheduling logic.
