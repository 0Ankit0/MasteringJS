Web Components

Build reusable custom HTML elements with encapsulated behavior and styles.

Core technologies

  • Custom Elements: define new tags.
  • Shadow DOM: encapsulate markup/style.
  • HTML Templates: reusable markup chunks.
class HelloCard extends HTMLElement {
  connectedCallback() {
    this.innerHTML = "<div>Hello from custom element!</div>";
  }
}
customElements.define("hello-card", HelloCard);
