Server-Sent Events (SSE)

SSE lets a server push one-way real-time updates to the browser over standard HTTP.

When SSE is a good fit

  • Live dashboards and notifications.
  • Activity feeds and status updates.
  • Any server → client stream where client doesn’t need a full duplex channel.

SSE vs WebSocket (quick rule)

Use SSE for simple server-to-client streams. Use WebSocket when the client must send frequent realtime messages back.

Client code

const source = new EventSource("/events");
source.onmessage = (event) => {
  console.log("SSE data:", event.data);
};
source.onerror = () => {
  console.error("SSE connection error");
};
