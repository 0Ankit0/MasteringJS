Periodic Background Sync API

Allows installed web apps to sync data periodically in the background via Service Workers.

Requirements

  • Service Worker
  • Secure context
  • Browser support + permission policies
const registration = await navigator.serviceWorker.ready;
await registration.periodicSync.register("content-sync", {
  minInterval: 24 * 60 * 60 * 1000
});

Example page: Periodic Sync Example.

This API is not widely available. Always build a foreground/manual sync fallback.
