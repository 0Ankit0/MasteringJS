Sensor APIs

Access device sensor data (light, motion, orientation, etc.) when available and permitted.

Important considerations

  • Needs permissions and often secure context.
  • Support differs across browsers and devices.
  • Always provide fallback behavior.
if ("AmbientLightSensor" in window) {
  const sensor = new AmbientLightSensor();
  sensor.addEventListener("reading", () => {
    console.log("Lux:", sensor.illuminance);
  });
  sensor.start();
}

See the dedicated example: Ambient Light Example.
