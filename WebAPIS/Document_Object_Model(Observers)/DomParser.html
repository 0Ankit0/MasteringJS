DOM Parser Tutorial

DOMParser API

DOMParser converts text (usually HTML or XML) into a real Document object that JavaScript can query and manipulate.

Why this is useful

  • Parse HTML responses before injecting content into the page.
  • Extract specific elements from incoming markup.
  • Build safer pipelines that inspect content first.

Step-by-step example

const htmlString = `
  <article>
    <h2>New post</h2>
    <p>Loaded from an HTML string.</p>
  </article>
`;

const parser = new DOMParser();
const doc = parser.parseFromString(htmlString, "text/html");

const title = doc.querySelector("h2")?.textContent;
console.log(title); // "New post"

Best practice

Avoid assigning untrusted HTML directly to innerHTML without sanitization. Parse, validate, and then render only what your app expects.
